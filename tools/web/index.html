Murmel

Mumble voice chat for GNOME
Written in Go with GTK 4 and Libadwaita · Version @VERSION@

Install↗ Source on GitHub

Features

Native GNOME app

GTK 4 and Libadwaita, adaptive from phone to desktop, light and dark style, keyboard and screen reader support. English and German.

Clear voice

Opus over encrypted UDP with TCP fallback, noise suppression, echo cancellation, voice activation or push-to-talk.

Chat

Channel and private messages with formatting, emoji and images, notifications and event sounds.

Channels at a glance

Channel tree with avatars and speaking indicators, descriptions with cover images.

Connections and identities

Saved servers, securely stored passwords, mumble:// links, certificates managed in the app.

Server administration

Edit channels, groups and permissions; kick, ban and manage registered users.

Install

Flatpak (recommended, with updates)

Requires ↗ Flatpak. The GNOME runtime comes from Flathub, which Flatpak offers to add during the installation if it is not set up yet.

In a terminal:

flatpak install --user @URL@@APP_ID@.flatpakref

Run it from the app grid or with flatpak run @APP_ID@. Updates arrive through the Software app or flatpak update.

If Flatpak was not installed before, Murmel may only appear in the app grid after you log out and back in.

Fedora: RPM packages

For Fedora 45 and newer, from ↗ Copr, with updates through dnf:

sudo dnf copr enable one337/murmel
sudo dnf install murmel

NixOS and Nix

Murmel is a Nix ↗ flake. Install it into your user profile:

nix --extra-experimental-features 'nix-command flakes' profile add github:one337/murmel/stable

Update it later with:

nix --extra-experimental-features 'nix-command flakes' profile upgrade murmel

For the latest development state, use github:one337/murmel/main instead; it may contain unreleased and less tested changes.

--extra-experimental-features turns flakes on for this one command. To turn them on permanently, so that plain nix profile add github:one337/murmel/stable and nix profile upgrade murmel work:

  • on NixOS, add nix.settings.experimental-features = [ "nix-command" "flakes" ]; to your system configuration (for example /etc/nixos/configuration.nix) and run sudo nixos-rebuild switch;
  • with Nix on another distribution, add the line experimental-features = nix-command flakes to ~/.config/nix/nix.conf.

Alternatives

Single file: download murmel-@VERSION@.flatpak and install it. Later updates still come from the repository.

flatpak install --user murmel-@VERSION@.flatpak

Add the repository only (signing key: murmel.gpg):

flatpak remote-add --user --if-not-exists murmel @URL@murmel.flatpakrepo
