Murmel

Mumble voice chat for GNOME · Version @VERSION@

Install (recommended, with updates)

Requires Flatpak. The GNOME runtime comes from Flathub, which Flatpak offers to add during the installation if it is not set up yet.

Install Murmel

Or in a terminal:

flatpak install --user @URL@@APP_ID@.flatpakref

Updates then arrive automatically through the Software app or with flatpak update.

If Flatpak was not installed before, you may have to restart the computer before Murmel starts from the app grid.

Run

flatpak run @APP_ID@

Fedora: RPM packages

Murmel is also available as an RPM from Copr, with updates through dnf:

sudo dnf copr enable one337/murmel
sudo dnf install murmel

NixOS

Requires flakes. Updates with nix profile upgrade murmel.

nix profile add github:one337/murmel

Alternative: single file

Download murmel-@VERSION@.flatpak and install it:

flatpak install --user murmel-@VERSION@.flatpak

Installed this way, Murmel still gets later updates from this repository.

Add the repository only

flatpak remote-add --user --if-not-exists murmel @URL@murmel.flatpakrepo

Signing key: murmel.gpg
