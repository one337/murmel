Murmel

Mumble-Sprachchat für GNOME · Version @VERSION@

Installieren (empfohlen, mit Updates)

Voraussetzung: Flatpak mit Flathub (Anleitung).

Murmel installieren

Oder im Terminal:

flatpak install --user @URL@@APP_ID@.flatpakref

Updates kommen danach automatisch über die Software-App oder mit flatpak update.

Starten

flatpak run @APP_ID@

Alternativ: einzelne Datei

murmel-@VERSION@.flatpak herunterladen und installieren:

flatpak install --user murmel-@VERSION@.flatpak

Auch so installiert bezieht Murmel spätere Updates aus diesem Repository.

Nur das Repository hinzufügen

flatpak remote-add --user --if-not-exists murmel @URL@murmel.flatpakrepo

Signaturschlüssel: murmel.gpg
